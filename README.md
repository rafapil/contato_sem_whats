# Zap sem Contato

**Versão:** 2.0.0  
**Plataformas:** iOS | Android

---

## Descrição

Zap sem Contato é um aplicativo para criar links wa.me do WhatsApp sem adicionar o contato. Permite criar, salvar e exportar links de forma rápida e segura.

**100% Local** — Todos os dados ficam armazenados apenas no seu dispositivo.

---

## Funcionalidades

- **Criar links wa.me**: Gere links para iniciar conversas no WhatsApp sem salvar o número
- **Abrir WhatsApp direto**: Abra uma conversa no WhatsApp com uma mensagem pré-definida
- **Salvar links**: Mantenha uma lista de links salvos para uso posterior
- **Limpar links**: Exclua todos os links salvos de uma vez
- **Exportar**: Exporte sua lista de links em formato XLS ou CSV

---

## Como usar

1. Selecione o DDI do país
2. Digite o número de telefone
3. (Opcional) Digite uma mensagem
4. Clique em **"Criar Link"** para gerar
5. Use **"Copiar"** para copiar o link ou **"Abrir WhatsApp"** para iniciar a conversa
6. Salve links para consulta posterior usando **"Salvar Link"**

## Política de Privacidade

**Última atualização:** 20 de setembro de 2026  
**Versão:** 1.0.0

### 1. Introdução

O **Zap sem Contato** é um aplicativo que prioriza sua privacidade. Não coletamos, transmitimos ou compartilhamos dados pessoais.

Este documento explica de forma clara e transparente quais dados são coletados, como são armazenados e quais são os seus direitos em relação às suas informações.

**Nossa premissa fundamental:** o Zap sem Contato não coleta, não transmite e não compartilha quaisquer dados pessoais dos usuários.

### 2. Dados coletados

O app armazena apenas **localmente no dispositivo**:
- Telefone e mensagem que você insere para criar links
- Lista de links salvos por você
- Preferências de uso

### 3. O que NÃO coletamos

- Não coletamos nome, e-mail ou dados pessoais identificáveis
- Não coletamos localização
- Não acessamos sua lista de contatos
- Não usamos cookies ou rastreadores
- Não fazemos uso de serviços de analytics
- Não temos sistema de login ou autenticação
- Não possuímos servidores ou backend — o app funciona inteiramente offline

### 4. Armazenamento

Todos os dados ficam armazenados **exclusivamente no seu dispositivo**. Para excluir todos os dados, basta desinstalar o aplicativo.

### 5. Links wa.me

O app gera links no formato wa.me utilizando a API pública do WhatsApp. Não temos controle sobre os termos de privacidade da Meta/WhatsApp.

### 6. Seus direitos

| Direito | Como exercer |
|---------|-------------|
| Acessar dados | Todos os dados estão visíveis dentro do app |
| Excluir dados | Exclua links individualmente, use "Limpar links", ou desinstale o app |
| Exportar dados | Use a função de exportação em XLS ou CSV |

### 7. Compartilhamento externo

Quando você cria um link wa.me e o compartilha, a geração e abertura desse link estão sujeitas às políticas de privacidade da **Meta Platforms, Inc.** (whatsapp.com).

### 8. Updates desta política

Esta Política de Privacidade pode ser atualizada periodicamente. Alterações significativas serão comunicadas por meio da atualização da data de "Última atualização" neste documento.
